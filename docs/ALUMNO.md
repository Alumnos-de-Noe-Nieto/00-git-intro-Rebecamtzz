## ¿Qué es Git?

Git es una herramienta que sirve para guardar los cambios que hacemos en un
proyecto y poder ver su historial. También permite que varias personas trabajen
en el mismo archivo sin perder información.

## Por qué necesitamos Git

Sin Git sería muy fácil borrar o sobrescribir el trabajo de otros compañeros.
Git ayuda a organizar los cambios, mantener un historial y trabajar en equipo
de forma segura.

## Los 3 conceptos clave de Git

1. **Repositorio:** Es la carpeta donde se guarda el proyecto y todos sus cambios.
2. **Commit:** Es un guardado de los cambios con un mensaje que explica qué se hizo.
3. **Rama:** Es una copia del proyecto para trabajar sin afectar la versión principal.

## Los comandos que aprendí

- `git init`
- `git add`
- `git commit`
- `git push`
- `git pull`
